# Android generated project README

## Multi-Model Comparison Interface APK

This repository contains a scaffolded Android app for a multi-model comparison interface. It is designed so Claude or another coding agent can continue developing the app and eventually generate a working APK in this repo.

### Included
- Android app skeleton with Gradle configuration
- Material 3 UI for a prompt comparison screen
- Side-by-side result cards for multiple AI models
- Basic logic to compare prompt outputs

### Open in Android Studio
1. Open this repository in Android Studio.
2. Let Gradle sync the project.
3. Build > Build APK or Run > Run 'app'.

### Notes
- The initial scaffold is intentionally simple and ready for iteration.
- Add model APIs, persistence, or export features as needed.
- If you want a signed APK for release, configure signing in the Android Studio build settings.
